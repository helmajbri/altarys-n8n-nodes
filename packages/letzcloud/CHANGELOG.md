# Changelog

## 0.1.0 (unreleased)

- LetzCloud node: instances, volumes, snapshots, networks, Kubernetes clusters, containers, databases, DNS zones and records; invoices, usage and wallet of the customer a key belongs to.
- Wait for State (instance) and Wait Until Running (Kubernetes cluster, followed through its create job), at most 7,200 seconds per execution.
- LetzCloud Trigger with webhook signature v2 verification, for a provider key or a customer key.
- LetzCloud API credential, tested against the appliance discovery route and then an authenticated route.
